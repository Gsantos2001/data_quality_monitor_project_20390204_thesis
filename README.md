# Σύστημα Παρακολούθησης και Αξιολόγησης Ποιότητας Δεδομένων

**Έκδοση 0.1.0 — λειτουργικό πρωτότυπο για τη διπλωματική εργασία**

Εφαρμογή γραμμής εντολών γραμμένη σε Python, η οποία εισάγει αρχεία CSV, ελέγχει βασικά χαρακτηριστικά ποιότητας και παράγει αναφορές χωρίς να τροποποιεί το αρχικό αρχείο.

## Δυνατότητες

- Έλεγχος ελλιπών τιμών ανά στήλη (κενά, μόνο κενά διαστήματα, προαιρετικά `NULL`, `N/A`, `NaN`).
- Έλεγχος πλήρως διπλότυπων εγγραφών και μοναδικότητας επιλεγμένων στηλών.
- Κανόνες εγκυρότητας: αριθμητικά όρια, ακέραιες τιμές, επιτρεπόμενες κατηγορίες, regex, συγκεκριμένη μορφή ημερομηνίας.
- Κανόνες συνέπειας: σύγκριση δύο πεδίων (αριθμοί, ημερομηνίες, κείμενο) και επαλήθευση `ποσότητα × τιμή = σύνολο` με ανοχή.
- Μετρήσεις πλήθους/ποσοστών ανά έλεγχο, με σαφή παρονομαστή.
- Διάκριση `completed` (ο έλεγχος εκτελέστηκε), `skipped` (δεν εκτελέστηκε), `error` (τεχνικό σφάλμα). Ολοκληρωμένος έλεγχος μπορεί να περιέχει προβλήματα.
- Αναφορές `report.json`, `checks.csv`, `findings.csv` και `summary.txt` σε νέο φάκελο ανά εκτέλεση.
- Η αρχική πηγή CSV **δεν τροποποιείται**.

## Απαιτήσεις

- Python 3.10 ή νεότερη
- Pandas, NumPy και pytest (για τις δοκιμές)

## Εγκατάσταση

Αποσυμπίεσε το έργο και άνοιξε ένα τερματικό μέσα στον φάκελο `data_quality_monitor_project`.

**Windows PowerShell:**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m data_quality_monitor --input examples/sample_data.csv --rules examples/rules.json --output reports
```

Αν η ενεργοποίηση αποκλείεται από την πολιτική του PowerShell, μπορείς να καλέσεις απευθείας `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` και μετά `.\.venv\Scripts\python.exe -m data_quality_monitor ...`.

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m data_quality_monitor --input examples/sample_data.csv --rules examples/rules.json --output reports
```

Τα αποτελέσματα θα βρίσκονται μέσα στον νέο φάκελο `reports/run_.../`.

Για βοήθεια στις παραμέτρους:

```bash
python -m data_quality_monitor --help
```

## Εκτέλεση σε δικό σου CSV

```bash
python -m data_quality_monitor --input "C:/data/dataset.csv" --rules examples/rules.json --output reports
```

Οι έλεγχοι εγκυρότητας και συνέπειας αναφέρονται σε συγκεκριμένα ονόματα στηλών. **Προσαρμόζεις τα `column`, `left`, `right`, `result` και `columns` στο δικό σου αρχείο.** Εάν κάποια στήλη δεν υπάρχει, ο αντίστοιχος έλεγχος καταγράφεται ως `skipped` — δεν αναφέρεται ψευδώς ότι δεν εντοπίστηκαν προβλήματα.

Χωρίς `--rules` εκτελούνται μόνο ο έλεγχος ελλιπών τιμών και ο έλεγχος πλήρως διπλότυπων γραμμών:

```bash
python -m data_quality_monitor --input examples/sample_data.csv
```

## Μορφή κανόνων

Το αρχείο `examples/rules.json` περιέχει λειτουργικά παραδείγματα. Οι βασικές κατηγορίες είναι:

- `missing_tokens`: συμβολοσειρές που θεωρούνται ελλιπείς (αγνοώντας κεφαλαία και περιττά κενά). Το κενό πεδίο αναγνωρίζεται πάντοτε.
- `duplicate_checks`: πίνακας κανόνων με `id` και `columns: null` (όλες οι στήλες) ή π.χ. `columns: ["product_id"]` (μοναδικότητα κωδικού).
- `validity_checks`: κανόνες `numeric_range` (`min`, `max`, προαιρετικά `integer`), `allowed_values`, `regex`, `date_format`.
- `consistency_checks`: `comparison` (`left`, `right`, `operator`, `data_type`, και `format` για ημερομηνίες) ή `product_equals` (`left`, `right`, `result`, `tolerance`).

Οι ημερομηνίες στο παράδειγμα ακολουθούν τη μορφή `%Y-%m-%d`. Η εφαρμογή δεν αλλάζει αυτόματα τη μορφή των αρχικών τιμών.

## Συνθετικά δεδομένα και αναμενόμενα αποτελέσματα

Το `examples/sample_data.csv` έχει 12 εγγραφές στις οποίες έχουν εισαχθεί εσκεμμένα προβλήματα. Με τους κανόνες `examples/rules.json` αναμένονται:

| Έλεγχος | Αναμενόμενα προβλήματα | Θέσεις εγγραφών |
|---|---:|---|
| Ελλιπές `product_name` | 3 | 2, 9, 10 |
| Πλήρως διπλότυπες εγγραφές (επιπλέον εμφανίσεις) | 1 | 7 |
| Επαναλαμβανόμενο `product_id` (επιπλέον εμφανίσεις) | 2 | 7, 8 |
| Μη έγκυρη `quantity` | 1 | 3 |
| Μη έγκυρη `unit_price` | 2 | 4, 11 |
| Μη αποδεκτή `category` | 1 | 5 |
| Μη έγκυρη `start_date` | 1 | 6 |
| Ανακολουθία ημερομηνιών | 1 | 12 |
| Ασυμφωνία συνολικής τιμής | 1 | 12 |

Οι αριθμοί θέσεων αρχίζουν από **1 για την πρώτη εγγραφή δεδομένων** (δεν περιλαμβάνεται η επικεφαλίδα). Δεν ισοδυναμούν απαραίτητα με αριθμούς φυσικών γραμμών του αρχείου CSV, εάν υπάρχουν πολύγραμμες τιμές μέσα σε εισαγωγικά.

Το συνολικό πλήθος προβλημάτων **δεν** αποτελεί το πλήθος μοναδικών προβληματικών εγγραφών, επειδή μία εγγραφή μπορεί να παραβιάζει περισσότερους κανόνες.

## Ερμηνεία αποτελεσμάτων

- `issue_rate_percent = issue_count / checked_count × 100` για ολοκληρωμένους ελέγχους με θετικό πλήθος εξεταζόμενων περιπτώσεων.
- Οι ελλιπείς τιμές **εξαιρούνται** από τους ελέγχους εγκυρότητας και συνέπειας. Αναφέρονται αυτόνομα.
- Στους ελέγχους συνέπειας, μη αναγνώσιμες αριθμητικές/ημερομηνιακές τιμές δεν χαρακτηρίζονται αυτομάτως ως ασυνέπειες· εξαιρούνται από τη σύγκριση και πρέπει να εντοπίζονται με ξεχωριστό κανόνα εγκυρότητας.
- Σε ελέγχους με βάση κωδικό, ελλιπή αναγνωριστικά εξαιρούνται από τη σύγκριση μοναδικότητας.
- Αν δεν υπάρχουν εξεταζόμενες περιπτώσεις, ο έλεγχος εμφανίζεται ως `skipped` και οι αριθμητικοί δείκτες είναι `null` (μη διαθέσιμοι), όχι 0.
- `completed` περιγράφει επιτυχή **εκτέλεση**, όχι απαραίτητα καλή **ποιότητα δεδομένων**.
- Δεν υπολογίζεται συνολική «βαθμολογία ποιότητας» επειδή δεν έχει ακόμη σχεδιαστεί επιστημονικά τεκμηριωμένη μέθοδος συνδυασμού δεικτών.

## Όρια αρχικής έκδοσης

Η έκδοση αυτή διαθέτει διεπαφή γραμμής εντολών, όχι γραφικό περιβάλλον. Απαιτεί ρητούς κανόνες για την εγκυρότητα/συνέπεια, δεν διορθώνει σφάλματα, δεν επαληθεύει την πραγματική αλήθεια μιας τιμής από εξωτερικές πηγές και δεν κάνει ανίχνευση ακραίων τιμών. Προβλέπονται δοκιμές απόδοσης και πιθανές επεκτάσεις πριν οριστικοποιηθεί το περιεχόμενο των Κεφαλαίων 5–6.

**Έλεγχος ασφάλειας δεδομένων:** Τα αποτελέσματα περιέχουν αναγνωριστικά εγγραφών και πληροφορίες ελέγχων. Χρησιμοποίησε μόνο κατάλληλα δεδομένα και μην κοινοποιείς αναφορές με ευαίσθητες πληροφορίες.

## Στοιχεία αναπαραγωγιμότητας

Η αναφορά JSON καταγράφει τις εκδόσεις Python/Pandas/NumPy, την υπολογισμένη διάρκεια φόρτωσης και ελέγχων, καθώς και SHA-256 αποτυπώματα του αρχικού CSV και των κανόνων. Τα αποτυπώματα βοηθούν να ελεγχθεί ότι δύο εκτελέσεις βασίζονται στο ίδιο περιεχόμενο. Ο χρόνος αποτελεί *ενδεικτική μέτρηση* για το συγκεκριμένο μηχάνημα και **δεν** αποτελεί από μόνος του γενικό συμπέρασμα απόδοσης.
