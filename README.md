## Περίληψη

Η ποιότητα των δεδομένων αποτελεί σημαντικό παράγοντα για την αξιοπιστία και την ορθή λειτουργία των σύγχρονων πληροφοριακών συστημάτων. Δεδομένα που περιέχουν ελλιπείς, διπλότυπες, μη έγκυρες ή ασυνεπείς καταχωρίσεις μπορούν να επηρεάσουν αρνητικά τις διαδικασίες επεξεργασίας και ανάλυσης, οδηγώντας σε ανακριβή αποτελέσματα.

Σκοπός της παρούσας διπλωματικής εργασίας ήταν η σχεδίαση και ανάπτυξη ενός λογισμικού συστήματος για την αυτοματοποιημένη αξιολόγηση και την ιστορική παρακολούθηση της ποιότητας δεδομένων. Το σύστημα υλοποιήθηκε με τη χρήση της γλώσσας προγραμματισμού Python και υποστηρίζει την εισαγωγή δεδομένων από αρχεία CSV και τον καθορισμό κανόνων αξιολόγησης μέσω εξωτερικών αρχείων JSON. Οι μηχανισμοί που αναπτύχθηκαν εξετάζουν την πληρότητα, τη μοναδικότητα, την εγκυρότητα και τη συνέπεια των δεδομένων, καθώς και το μήκος κειμενικών καταχωρίσεων.

Μετά την ολοκλήρωση των ελέγχων, η εφαρμογή δημιουργεί αναφορές σε μορφές JSON, CSV και TXT, στις οποίες καταγράφονται τα προβλήματα που εντοπίστηκαν και οι αντίστοιχοι δείκτες ποιότητας. Παράλληλα, αναπτύχθηκε μηχανισμός ιστορικής παρακολούθησης (Monitoring), ο οποίος επιτρέπει τη σύγκριση αποτελεσμάτων διαφορετικών εκτελέσεων και τον εντοπισμό μεταβολών στα ποσοστά προβλημάτων.

Για την αξιολόγηση της λειτουργίας του συστήματος πραγματοποιήθηκαν 49 αυτοματοποιημένες δοκιμές, οι οποίες ολοκληρώθηκαν επιτυχώς. Η πειραματική αξιολόγηση πραγματοποιήθηκε με πραγματικά δεδομένα NYC 311, χρησιμοποιώντας σύνολα έως 1.000.000 εγγραφές και 53 κοινούς ελέγχους ποιότητας. Η εισαγωγή 140 ελεγχόμενων αλλοιώσεων επέτρεψε την επαλήθευση του εντοπισμού τους στις αντίστοιχες εγγραφές και στους σωστούς κανόνες. Σε ξεχωριστό συμπληρωματικό πείραμα με 54 ελέγχους επιβεβαιώθηκε επίσης ο εντοπισμός 20 ελεγχόμενων αλλοιώσεων κατηγορικών τιμών.

Επιπλέον, μέσω τεσσάρων διαδοχικών αξιολογήσεων εξετάστηκε η λειτουργία ιστορικής παρακολούθησης, κατά την οποία το σύστημα αναγνώρισε σωστά τις περιπτώσεις σταθερότητας, επιδείνωσης και βελτίωσης του επιλεγμένου δείκτη ποιότητας.

Παράλληλα, πραγματοποιήθηκαν μετρήσεις χρόνου εκτέλεσης και χρήσης μνήμης, καθώς και συγκριτική αξιολόγηση με υβριδική υλοποίηση που χρησιμοποιεί τις βιβλιοθήκες Pandas και Pandera. Από τη σύγκριση επιβεβαιώθηκε η συμφωνία των συγκεντρωτικών αποτελεσμάτων των κοινών ελέγχων, ενώ η αρχική εφαρμογή παρουσίασε μικρότερους χρόνους εκτέλεσης και χαμηλότερη παρατηρηθείσα χρήση μνήμης στις συγκεκριμένες πειραματικές συνθήκες.

Τα αποτελέσματα έδειξαν ότι, για τους κανόνες, τα δεδομένα και τα σενάρια που εξετάστηκαν, το σύστημα μπόρεσε να εντοπίσει και να καταγράψει τα αναμενόμενα προβλήματα ποιότητας, καθώς και να παρακολουθήσει τη μεταβολή τους μεταξύ διαφορετικών εκτελέσεων. Η εφαρμογή αποτελεί μια λειτουργική βάση για την αυτοματοποιημένη αξιολόγηση και παρακολούθηση της ποιότητας δεδομένων, με δυνατότητες περαιτέρω επέκτασης.

**Επιστημονική περιοχή:** Πληροφοριακά Συστήματα και Διαχείριση Δεδομένων

**Λέξεις-κλειδιά:** ποιότητα δεδομένων, αξιολόγηση ποιότητας δεδομένων, παρακολούθηση ποιότητας δεδομένων, πληροφοριακά συστήματα, Python



## 1. Περιγραφή και δυνατότητες

Το Data Quality Monitor είναι μια εφαρμογή Python για την αυτοματοποιημένη αξιολόγηση και την ιστορική παρακολούθηση της ποιότητας δεδομένων.

Οι βασικές δυνατότητες του συστήματος είναι:

- Ανάγνωση δεδομένων από αρχεία CSV.
- Παραμετροποίηση κανόνων αξιολόγησης μέσω αρχείων JSON.
- Έλεγχοι πληρότητας, μοναδικότητας, εγκυρότητας και συνέπειας.
- Έλεγχοι αριθμητικών ορίων, επιτρεπόμενων τιμών, ημερομηνιών και μήκους κειμένου.
- Παραγωγή αναφορών σε μορφές JSON, CSV και TXT.
- Ιστορική σύγκριση αποτελεσμάτων διαφορετικών αξιολογήσεων.
- Καταγραφή μεταδεδομένων και ψηφιακών αποτυπωμάτων SHA-256.

Η εφαρμογή λειτουργεί μέσω γραμμής εντολών (CLI), χωρίς να τροποποιεί τα αρχικά δεδομένα.

## 6. Παραγόμενες αναφορές

Κάθε αξιολόγηση δημιουργεί ξεχωριστό φάκελο με χρονική σήμανση και τα ακόλουθα αρχεία:

Οι διαθέσιμες καταστάσεις είναι completed, skipped και error.

## 7. Ιστορική παρακολούθηση

Η λειτουργία Monitoring επιτρέπει τη σύγκριση αποτελεσμάτων διαφορετικών αξιολογήσεων για συγκεκριμένο έλεγχο ποιότητας.

Απαιτούνται συγκρίσιμες αναφορές με τους ίδιους κανόνες και το ίδιο αναγνωριστικό συνόλου δεδομένων ή, όταν δεν έχει καθοριστεί αναγνωριστικό, το ίδιο όνομα αρχείου εισόδου.

Παράδειγμα εκτέλεσης:

```powershell
python -m data_quality_monitor --input examples/sample_data.csv --rules examples/rules.json --output reports_products --dataset-id products

python -m data_quality_monitor --input examples/monitoring_case/sample_data.csv --rules examples/rules.json --output reports_products --dataset-id products

python -m data_quality_monitor monitor --reports reports_products --check "missing:product_name" --dataset-id products --output monitoring_reports
```

Οι μεταβολές εκφράζονται σε ποσοστιαίες μονάδες και χαρακτηρίζονται ως:

- improved: βελτίωση
- worsened: επιδείνωση
- unchanged: σταθερότητα

Τα αποτελέσματα αποθηκεύονται σε μορφές JSON και CSV.
